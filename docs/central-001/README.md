# Home — raio-X do mês

- Cada bloco de dados declara origem, competência e referência em selo próprio.
- Cenário demonstrativo, carga de teste, export e planejamento são universos separados: seus valores nunca são somados.
- MRR mede apenas recorrência; habilitação e serviço são não recorrentes (NR), apresentados separadamente.
- Forecast, movimentos e pipeline ficam em Gestão de vendas, não na Home.
- Diretorias 2027 e a base declarada no planejamento ficam em Territórios. Os valores de planejamento desta demonstração são fictícios.
- A tabela de segmentos oferece os cortes Todos, Novos e Base; o recorte acompanha o link para Territórios.
- A evolução semanal apresenta semanas 1 a 5, sem estimar valores ausentes.
- Percentuais vêm acompanhados dos valores absolutos do mesmo universo; totais são calculados por soma, nunca por média de percentuais.
- No modo visual, o export é identificado como sintético; a quantidade de filiais vem dos dados carregados.
