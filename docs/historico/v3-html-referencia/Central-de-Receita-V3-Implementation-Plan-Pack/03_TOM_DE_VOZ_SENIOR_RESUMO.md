# Tom de voz Senior — resumo operacional para a V3

Fonte: arquivo enviado pelo usuário `TOM DE VOZ MARCA SENIOR.html`.

## Princípios
- Linguagem clara e direta.
- Frases curtas, sem jargões desnecessários.
- Tom profissional, humano e acessível.
- Erros explicativos, não punitivos.
- Voz ativa.
- Ser específico com quantidades, datas e valores.
- CTAs e botões devem usar verbos.
- Evitar abreviações desnecessárias e termos técnicos de sistema.
- Regra de ouro: o texto deve soar como algo que uma pessoa real falaria.

## Aplicação na Visão Comercial
Usar:
- “Ver o briefing completo”
- “O forecast mudou desde a fotografia oficial.”
- “3 oportunidades saíram do forecast oficial.”
- “R$ 1,0 mi entrou no mês.”

Evitar:
- “Persistir estado”
- “Forecast crítico” sem régua formal
- “Erro do executivo”
- “Disparar cobrança”
- “Timeout”, “exception”, “null” ou linguagem técnica para usuário final
